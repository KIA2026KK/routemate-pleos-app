# 목적지 자동 등록과 간단한 동행 통화

## 기본 흐름

테스트 앱의 첫 목적지는 **광주송정역**이다. 앱을 열면 목적지 등록과 **3km 검색**을 자동 수행한다.
목적지 카드, 거리 선택, 동행 목록만 기본 화면에 배치한다. 테스트 차량·목적지는 명시적으로 표시하며 실제 VIN으로 가장하지 않는다.
일반 테스트 APK의 음성은 백엔드 발급 토큰과 실제 LiveKit Cloud를 사용한다. 별도 `.prototype` 앱은 화면 체험용이다.

**앱 실행 → 동행 선택(또는 방 만들기) → 마이크 켜기**가 기본 시나리오다.
방 참여 후 음성 연결을 자동 시작하며 첫 마이크 상태는 음소거다. 마이크 권한은 연결 시점에 요청한다.
방은 기본 공개·4명이며, 이름을 자동 채운다. 정원 2~8명·비공개 설정은 만들기 창의 옵션에 둔다.

## 목적지 선택

- 검색 아이콘 → 정차 확인 → 장소명·도로명 입력 → 주소가 표시된 결과 선택 순서.
- `광주송정역`과 `광주광역시 광산구 상무대로 201`, `서울역`과 `서울특별시 용산구 한강대로 405`는 명시적인 예시 데이터.
- 다른 주소는 Android 기기의 Geocoder 서비스로 검색. API 키나 현재 위치 권한 없이 동작하지만 기기의 서비스 지원·네트워크에 의존.
- 기기 서비스 부재, 8초 지연, 통신 실패, 결과 없음은 서로 다른 안내. 실패한 검색을 임의 좌표로 바꾸거나 목적지에 자동 적용하지 않음.
- 타이핑 중 이전 검색 취소, 마지막 검색만 반영, 결과 최대 5개. 선택한 테스트 목적지는 앱 재실행 후에도 보존.
- 실제 Pleos 모드에서는 내비게이션 목적지가 기준이며 수동 검색으로 덮어쓰지 않음. SDK 실패를 예시 목적지로 대체하지 않음.
- 기존의 `샘플 목적지 가져오기`, 반복 설명, 큰 지도 예시, VIN 원문·좌표 표시는 기본 화면에서 제거.

주소 검색 근거: [Android Geocoder](https://developer.android.com/reference/android/location/Geocoder).
역 주소 근거: [철도산업정보센터 광주송정역](https://www.kric.go.kr/jsp/board/portal/sub05/est/estation_BasicDetail.jsp?q_station=A030280344).
예시 좌표는 테스트용 고정 좌표이며 실제 내비게이션 수신값과 구분.

## 유지 규칙

| 항목 | 규칙 |
| --- | --- |
| 검색 | 최종 목적지 기준 3km·5km, 기본 3km; 10km 거부 |
| 참가 | 차량 계정당 한 방; 중복 참여는 인원 증가 없이 같은 참가 반환 |
| 정원 | 기본 4명, 2~8명; 동시 입장도 DB에서 초과 차단 |
| 참가 유지 | 앱 표시 또는 활성 통화 중 20초마다 heartbeat; 90초 끊기면 서버 정리 |
| 활성 방 | 초기 2시간; 정상 heartbeat 시 남은 시간이 1시간 미만이면 2시간으로 연장 |
| 방 갱신 비용 | 방 만료 시각 갱신은 약 시간당 한 번; heartbeat마다 방 행 갱신 없음 |
| 빈 방 | 마지막 참가자 퇴장 시 닫힘; 닫힌 방 부활 없음 |
| 운행 | 목적지 갱신·heartbeat 없는 상태로 24시간이면 만료 |
| 음성 권한 | 서버 발급 60초 입장 토큰; DB 참가·세션 권한을 별도로 점검 |
| 화면 이탈 | Android 0.3부터 microphone foreground service로 통화 유지; 홈 상단 배너로 통화방 복귀 |
| 화면 회전 | Activity 구성 변경은 실제 화면 이탈과 구분하여 통화 유지 |
| 운행 종료 | 자동 등록의 같은 목적지 이벤트로 종료한 운행을 되살리지 않음; 재시작은 목적지 선택 |
| 목적지 변경 | 기존 방에서 퇴장·음성 해제 후 새 목적지 등록·재검색; 동기화 전 다른 목적지 방 참여 차단 |

짧은 heartbeat 오류는 미디어를 유지하며 재시도한다. 약 85초간 권한 갱신 실패 시 안전하게 음성을 중단한다.
SDK의 재연결 후에도 실패하면 새 토큰을 발급받아 제한된 재시도를 수행한다. 통신망 전환 중 무중단 음성을 보장하지 않는다.
실제 차량의 속도·기어 연동은 별도 검증 항목이다.

## 실기기 테스트 시나리오

두 Android 기기에 같은 최신 APK 설치. 가까운 단말은 이어폰 사용. 전체 최종 시나리오는 `SUBMISSION_CHECKLIST.md` 참고.

| 번호 | 조작 | 기대 결과 |
| --- | --- | --- |
| 1 | 앱 첫 실행 | 광주송정역·목적지 등록 완료·3km 선택, 등록 버튼 조작 없음 |
| 2 | 목적지 검색에서 `상무대로 201` 입력 | 광주송정역과 도로명 주소 결과; 선택 후 자동 등록·재검색 |
| 3 | 다른 도로명 검색 | 기기 검색 결과 또는 정확한 오류·결과 없음 안내; 잘못된 목적지 자동 적용 없음 |
| 4 | 한 기기에서 방 만들기 → 만들고 참여 | 이름 자동 입력, 기본 4명·공개, 연결 시작 후 음소거 |
| 5 | 다른 기기에서 새로고침 → 방 선택 | 같은 방 참여, 권한 허용 후 음성 연결; 별도 연결 버튼 조작 없음 |
| 6 | 두 기기에서 마이크 아이콘 누름 | 서로 음성 청취; 꺼짐/켜짐 아이콘·문구 일치 |
| 7 | 마이크 권한 거부 후 다시 허용 | 권한 필요 안내; 마이크 허용으로 재시도 가능 |
| 8 | 3km → 5km 선택 | 반경에 맞춰 목록 갱신; 10km 없음. 두 예시 목적지가 같으면 두 반경에서 검색되는 것이 정상 |
| 9 | 통화 중 화면 회전 | 음성 연결 유지; 실제 청취 확인 |
| 10 | 나가기 → 같은 방 다시 참여 | 인원 감소 후 새 참가 연결; 처음에는 음소거 |
| 11 | 통화방 메뉴 → 운행 종료 → 확인 | 방·음성 종료, 자동 재등록 없음; 목적지 선택으로 새 운행 가능 |
| 12 | Wi-Fi 중단·복구 후 새로고침 | 오류 안내와 서버 상태 반영; 만료 시 새 방 참여 후 재연결 |
| 13 | 홈 버튼·화면 잠금 후 앱 복귀 | 통화 알림·음성 유지, 상단 현재 방 배너로 복귀 |
| 14 | 주야간 아이콘·큰 글꼴 사용 | 상태 가독성, 아이콘 설명, 검색·참여·마이크 조작 가능 여부 확인 |

3km/5km 거리 경계, 동시 정원 제한, 2시간 유지 연장·만료 차단은 실제 PostGIS 통합 테스트로 별도 검증.
물리 단말 음질·에코·차량 오디오, 실제 Pleos VIN·목적지 수신, 실망 전환은 자동 시험과 구분해 기록.

문제 기록: 기종·Android 버전·발생 시각(KST)·화면 문구·재현 순서. 토큰·복구키·Secret 공유 제외.
