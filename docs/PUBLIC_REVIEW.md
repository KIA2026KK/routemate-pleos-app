# 공개 전 점검

2026-11-15, 앱·백엔드 로컬 작업 파일과 접근 가능한 모든 Git ref 이력 검사.
공식 배포의 체크섬을 검증한 **Gitleaks 8.30.1** 기본 규칙 사용.
로그·보고서는 `--redact=100`으로 값 전체 비공개 처리, 원본 비밀정보 출력 없음.

| 범위 | 결과 |
| --- | --- |
| 앱 이력 `git --log-opts="--all --full-history"` | 탐지 0 |
| 백엔드 이력 같은 조건 | 탐지 0 |
| 앱 추적 파일 + Git 제외되지 않은 신규 파일 | 탐지 0 |
| 백엔드 추적 파일 + Git 제외되지 않은 신규 파일 | 탐지 0 |
| 추적 중 `.env`·서명 keystore·개인키·Firebase 서비스 계정 파일 | 없음 |

원시 마스킹 보고서는 Git 제외된 `app/build/submission/security/`에 보관.
이 결과는 검사 도구의 탐지 범위이며 모든 형태의 비밀정보 부재를 보증하지 않습니다.
누락된 원격 ref, 서버 환경 변수, 사용자 홈의 개인 파일은 검사 대상이 아닙니다.
기록 재작성·강제 push·키 교체는 수행하지 않았습니다.

보완: 앱 `.gitignore`에 keystore/PKCS12/개인키/서비스 계정 제외, `apk/*.apk`만 제출 산출물 추적 허용.
`.env.example`에는 공개 서버 주소·선택 방법만 기록. release 비밀번호는 로컬 스크립트 입력 후 프로세스 환경으로만 전달.
Gradle wrapper JAR, 빌드 설정, 리소스, DB 마이그레이션은 유지.

GitHub API로 두 저장소가 private임을 확인했습니다. 공개 전환은 하지 않았습니다.
실제 공개 전 소유자 권한으로 GitHub Secret scanning·접근 설정을 추가 확인하고
2026-11-16까지 공개 후 2026-11-23까지 공개 유지 조건을 지킵니다.

현재 접근 가능한 Git 기록의 테스트 전용 문자열·공개 서버 주소는 실제 인증정보와 구분합니다.
실제 비밀정보가 나중에 발견되면 위치만 기록하고 소유자가 폐기·교체·기록 처리 방식을 결정합니다.
