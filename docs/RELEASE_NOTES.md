# RouteMate 0.3.0 — 제출 Release 설명 초안

팀: 노래말고 사람들과 함께

내비게이션 최종 목적지가 가까운 운전자를 연결하는 그룹 음성 통화 앱.
목적지 기준 3km·5km 검색, 방 생성·초대 코드·단일 방 참여,
전체 통화방·발화 표시·현재 방 배너·마이크 알림과 통화 유지 기능.

첨부 예정: `노래말고 사람들과 함께_RouteMate_release.apk`와 SHA-256 검증 파일.
**현재 미게시 / 팀 release 키 서명 대기.** 게시 후 실제 다운로드 링크와 해시로 갱신.

실행 대상: Pleos SDK 환경. 일반 Android 테스트용 Mock APK와 구분.
테스트 API: https://routemate-test-api.onrender.com

실행·설정·확인된 제약은 루트 README, 실제 검증은 `docs/TEST_RESULTS.md` 참고.
실제 Pleos 목적지·VIN·차량 오디오 및 두 물리 기기 청취는 별도 확인 필요.
