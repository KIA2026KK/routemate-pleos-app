저장소 통합·Release 게시·공개 전환·메일 발송은 수행하지 않습니다.

- [ ] 팀 소유 release 키를 저장소 밖에 생성·백업하고 로컬 서명 실행

- [ ] 실제 개발·검증에 사용한 Pleos 버전·화면 규격 확보. 조사 후보값으로 대체 금지
- [ ] 실제 Pleos 목적지·변경·취소, VIN, 차량 마이크·오디오 확인
- [ ] 두 물리 단말에서 실제 음성 청취·음소거·발화 표시·지속 통화 확인
- [ ] APK·최종 검증 기록을 추가한 로컬 커밋 생성 후 최종 커밋 번호 별도 기록

## 사용자가 진행할 게시 순서

1. [로컬 서명](RELEASE_SIGNING.md) 실행. 기본 제출 대상은 실제 SDK를 쓰는 Pleos이며 휴대폰 시험용은 별도 생성.
2. 아래 수동 시나리오와 실제 Pleos 검증 후 결과를 문서에 반영.
3. APK가 100 MiB 이하이면 `git add apk`로 포함. 초과하면 Git 추가 대신 GitHub Releases에 첨부하고 README·제출 폼에 **실제 게시된 Release URL** 기록.
4. 검토한 기능 브랜치를 원격 push → `develop` PR → CI 통과·머지 → `develop → main` PR → CI 통과·머지. 실패한 검증 우회 금지.
5. main에 최종 소스·README·APK 또는 Release 링크가 함께 있는지 확인. 제출하는 **원격 main 최종 커밋**을 별도 기록.
6. 두 저장소 모두 현재 private. **2026-11-16까지 public 전환, 2026-11-23까지 public 유지.** 공개 전 GitHub Secret scanning 결과도 확인.
7. 로그아웃/시크릿 창에서 두 저장소와 APK 다운로드를 직접 확인. 대표 저장소 주소와 최종 커밋 번호를 접수 정보에 입력.
8. 테스트 Render·DB·Redis·LiveKit을 심사 기간에 유지. Firebase App Distribution에는 서명 APK 업로드 후 테스터 등록·배포.
9. 실제 공모전 접수 화면/양식의 남은 항목 확인 후 사용자가 제출 또는 메일 발송.

## 최종 수동 테스트

두 실제 Android 기기에 **같은 Phone release APK**를 설치합니다. 이어폰을 사용해 가까운 기기의 하울링을 피합니다.
Pleos 제출 APK는 실제 Pleos 환경에서 별도로 수행합니다.

| 순서 | 동작 | 기대 결과 |
| --- | --- | --- |
| 1 | 첫 실행 | Phone은 광주송정역 자동 등록·3km 선택·Mock 표시, Pleos는 실제 내비게이션 목적지 |
| 2 | 장소·도로명 검색 후 선택(Phone) | 주소 표시, 선택한 목적지 등록·재검색, 무관한 좌표 대체 없음 |
| 3 | 방 만들기 / 다른 단말에서 3km·5km 검색 | 방·정원 표시, 기본 4명 공개 |
| 4 | 마이크 거부 후 다시 허용 | 권한 안내와 재시도, 첫 연결 음소거 |
| 5 | 두 참가자 마이크 켜고 번갈아 발화 | 서로 실제 청취, 발화자 테두리 변화, 꺼진 마이크 발화 표시 없음 |
| 6 | 통화방 뒤로가기 → 홈 배너 → 재진입 | 음성 유지, 현재 방으로 복귀 |
| 7 | 홈 이동·화면 잠금 상태로 3분 이상 통화 | 알림·음성·상대 발화 유지. 실제 청취 여부를 따로 기록 |
| 8 | 다른 방 선택·이동 확인, 잘못된 초대 코드·정원 초과 | 한 방만 참여. 거부된 이동은 원래 방 유지 |
| 9 | 비공개 방의 초대 코드로 참여 | 검색에 없는 방도 정확한 코드로 입장, 코드 오류 명확한 안내 |
| 10 | Wi-Fi → 이동통신 전환·짧은 장애·복구 | 재연결 상태 안내, 불필요한 즉시 퇴장 없음; 약 85초 권한 갱신 실패는 통화 정리 |
| 11 | 빨간 전화 아이콘 퇴장 | 음성 중단·참가자 감소·통화 알림 제거 |
| 12 | 운행 종료 | 운행·참여 종료, 같은 목적지 이벤트로 자동 부활 없음 |
| 13 | 실제 Pleos 목적지 변경·취소 | 새 목적지 반영·기존 통화 정리, Mock 대체 없음 |
| 14 | 가로 화면·큰 글꼴 | 버튼 가림·잘림 없이 뒤로가기·음소거·퇴장 가능 |

끊김 발생 시 통화방 메뉴 → 연결 정보에서 비밀정보 없는 진단을 복사하고 기종·Android 버전·KST 시각·재현 동작을 기록합니다.
사람이 들은 음성·차량 오디오 검증과 SDK 연결/트랙 검증을 같은 항목으로 합치지 않습니다.
